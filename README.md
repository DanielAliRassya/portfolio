## 📸 Preview

Website portfolio personal dengan desain minimalis modern, menggabungkan dark theme dengan gradien warna yang eye-catching.

---

## 🎨 Fitur Utama

- **Dark Theme** dengan aksen warna purple, pink, dan cyan
- **Fully Responsive** - optimal di semua ukuran layar
- **Typewriter Animation** di hero section
- **Smooth Scroll & Reveal Animations** saat scroll
- **Glassmorphism Effects** pada cards
- **Mobile Navigation** dengan hamburger menu
- **Contact Links** langsung ke Email, GitHub, dan LinkedIn

## 🚀 Cara Menjalankan

### Local Development
1. Clone repository ini:
   ```bash
   git clone https://github.com/danielalirassya/portfolio.git
   cd portfolio
   ```

2. Buka dengan Live Server atau:
   ```bash
   python3 -m http.server 8080
   ```
   
3. Buka `http://localhost:8080` di browser

### Deploy ke Vercel/Netlify
- Push ke GitHub
- Import repository di dashboard Vercel atau Netlify
- Done! 🎉
